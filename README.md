# Л. Чогдовын дурсгалд — Хүндэтгэлийн урилга

Нэрт сурган хүмүүжүүлэгч, хөгжмийн зохиолч Л. Чогдов багшийн дурсгалд зориулсан
шатрын нөхөрсөг тэмцээний интерактив урилга.

- **Огноо:** 2026.11.26, Пүрэв гараг (Бүх нийтийн амралтын өдөр), 09:30
- **Байршил:** Дүүрэн төв, 4 давхар
- **Төрлүүд:** Рапид 20′+20″ (түргэвчилсэн) · Блиц 3′+2″ (түргэн) · Бодлого бодолт: 2 нүүдлийн 2, 3 нүүдлийн 1 бодлого (МШХ-ны дотоод чансаа тооцно)
- **Шагнал:** Рапид 1–5 байр + шилдэг эмэгтэй · Блиц 1–3 байр · Бодлого бодолт 1–3 байр
- **Хураамж:** 50,000₮ (кофе, цай, 1, 2-р хоол, дессертийн багц багтсан) — Голомт банк 3100 1500 170 5036915
- **Холбоо барих:** Ч.Мөнхбат 8600 9908
- **Зохион байгуулагч:** ФМ, УШ Ч.Мөнхбат
- **Сайт:** https://mcf-chess.github.io/Urilga/

## Бүтэц

```
chogdov-urilga/
├── index.html          # Хуудасны бүтэц, төрлүүдийн карт, хөгжүүлэгчийн мэдээлэл
├── css/style.css       # Загвар, өнгө, хөдөлгөөн (фонт: Times New Roman)
├── js/
│   ├── config.js       # Бичвэр, төрлүүд, байршил, хуваарийг ЭНД засна
│   └── main.js         # Дугтуй нээх/хаах, хуваарийн цонх
├── assets/images/      # Архивын хоёр гэрэл зураг
└── assets/audio/       # Л. Чогдов «Эртний бүжиг» (урилга нээхэд тоглоно)
```

## Түгээмэл засварууд

| Юу засах | Хаана |
|---|---|
| Урилгын үндсэн бичвэр, байршил, зохион байгуулагч | `js/config.js` |
| Төрлүүдийн нэр, тайлбар | `js/config.js` → `categories` (мөн `index.html` дахь картууд) |
| Хуваарийн цаг | `js/config.js` → `schedule` |
| Огноо, хөгжүүлэгчийн мэдээлэл | `index.html` |
| Өнгө, фонт | `css/style.css` → `:root` |

## Компьютер дээр үзэх

`index.html`-ийг хөтөч дээр нээнэ, эсвэл VS Code-ийн **Live Server** ашиглана.

## Шинэчлэлт байршуулах

```bash
git add .
git commit -m "Засвар"
git push
```

1–2 минутын дараа сайтыг **Cmd + Shift + R** дарж шинэчилнэ.

## Хөгжим

Урилга нээх даралтаар `assets/audio/ertnii-bujig.mp3` зөөлөн эхэлж, давтан тоглоно.
Хаах, өөр таб руу шилжихэд зогсоно. Хөтчүүд хэрэглэгч дарахаас өмнө дуу тоглуулахыг
хориглодог тул линк нээгдэх мөчид биш, дугтуй дээр дарахад эхэлнэ.
Дууг солих бол ижил нэртэй MP3 файлаар сольж, `index.html` дахь «Эртний бүжиг» бичвэрийг засна.
